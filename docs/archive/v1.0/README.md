# Hark Daily — Archive v1.0 (Pre-Capacitor & Legacy Assets)

This directory archives historical planning documents, early UI mockups, promotional audio experiments, and unused screenshot variants created during the **v0.1.0 – v1.0.19** development cycles prior to the unified Capacitor cross-platform mobile shell migration.

---

## Contents

### 1. `docs/`
- **`android-plan.md`**: Early architecture blueprint for the initial Jetpack Compose Android prototype (October 2026) prior to standardizing on the unified Capacitor Android & iOS smart native shells.
- **`Hark-Podcast-Transformation-Plan.md`**: Architectural design notes for transitioning from single-narrator daily packs to the two-host dialogue podcast format (Matthew & Kelly).
- **`ui-mock/`**: Standalone HTML and CSS prototype boards (`Hark – Clean Player Mock.html`) used for early responsive layout experiments.

### 2. `media/`
- **`hark_daily_demo.mp4` / `hark_daily_demo.gif`**: Early desktop and mobile video captures of the briefing player.
- **`promo-audio/`**: Initial synthesis evaluation clips testing voice prosody and audio bridges (`hark_intro_original_*` and `hark_intro_enhanced_*`).

### 3. `screenshots/`
- Historical mobile and desktop screenshots, dark/light theme explorations, and superseded UI variants from earlier releases:
  - `desktop.png`, `mobile-dark.png`, `mobile-swipe.png`, `settings.png`
  - `android-playing-dark.png`, `android-settings-light.png`, `android-sources-light.png`, `android-today-dark.png`, `android-today-light.png`
  - `web-desktop-light.png`, `web-mobile-dark.png`, `web-mobile-light.png`

---
